# 임베디드 시스템 프로젝트 기획서 — 수어 지문자 인식 소통 보조 장치

> 걱정없조 · 박성규, 김성훈, 박태석

## 1. 개요

| 항목 | 내용 |
|------|------|
| 대상 | 공공기관 창구를 이용하는 청각장애인(농인)과 창구 직원 |
| 문제 | 직원 대부분이 수어를 모르고, 수어 통역은 연결될 때까지 기다려야 해서 창구에서 바로 대화하기 어렵다 |
| 해결 | 사용자가 카메라 앞에서 지문자(한글 자모를 손 모양으로 표현)를 하면, **라즈베리파이 4**가 자모를 인식해 문장으로 만들고 직원의 웹 화면으로 보낸다.|
| 유형 | 카메라·AI 확장형 (USB 카메라 + 이미지 인식 AI를 라즈베리파이에서 직접 구현) |

## 2. 시스템 구성

라즈베리파이 4 한 대가 **영상 인식, 장치 제어, 웹서버**를 모두 맡는다. 직원 PC는 별도 프로그램 없이 브라우저로 접속한다.

| 연결 | 오가는 데이터·명령 |
|------|--------------------|
| USB 카메라 → 라즈베리파이 | 사용자 손 영상 (320×240, 실시간) |
| 라즈베리파이 → OLED | 조합 중인 문장, AI 추천 단어, 직원 답변 |
| 라즈베리파이 → LED·부저 | 인식 상태 (손 없음 / 인식 중 / 확정), 확정 알림음 |
| 버튼 → 라즈베리파이 | 띄어쓰기, 지우기, 전송, 추천 선택 |
| 라즈베리파이 ↔ 직원 PC 브라우저 | 사용자 문장 → 직원 화면 / 직원 답변 → 라즈베리파이 (Wi-Fi, Flask-SocketIO) |
| 라즈베리파이 → DB | 대화 텍스트 기록 (SQLite, 영상은 저장하지 않음) |

|------|-----------|------|------|

## 4. 동작 과정

### 사용자 쪽 (라즈베리파이 안)
1. 카메라 영상을 320×240으로 줄이고 OpenCV로 좌우 반전·조명 보정(CLAHE)
2. MediaPipe Hands로 손 관절 21점 좌표 추출 → 손목 기준으로 위치·크기 정규화
3. AI 분류 모델이 **자음 14 + 모음 10 + 대기 = 25종** 중 하나로 판정
4. 같은 자모가 **확률 0.8 이상으로 0.6초 유지**되면 확정 → 초록 LED + 부저 "삑"
5. 확정된 자모를 한글 음절로 조합 (예: ㄷ ㅡ ㅇ → 등), 사전에서 단어를 추천해 OLED에 표시
6. 버튼으로 추천 선택·띄어쓰기·지우기, **[전송]** 버튼으로 직원 화면에 보냄

### 직원 쪽 (웹 화면)
- 사용자 메시지를 실시간으로 확인 (AI가 보정한 경우 원문도 함께 표시)
- 빠른 답변 버튼("신분증을 보여주세요" 등) 또는 직접 입력으로 답변 → 사용자 OLED에 표시
- 손 인식 상태, 처리 속도(FPS), 대화 기록 확인

## 5. 기능 범위

| 구분 | 기능 |
|------|------|
| **기본 기능** (반드시 구현) | 지문자 24자 + 대기 인식, 한글 조합, OLED·LED·부저 피드백, 버튼 입력, 웹 화면 양방향 송수신, 대화 기록 저장 |
| **선택 기능** (기본 완성 후) | AI 단어 추천·오인식 보정, 직원 빠른 답변, 쌍자음 입력(버튼 길게), 부팅 시 자동 실행 |
| **제외** | 단어·문장 수어 번역, 영상 저장, 실제 공공기관 설치 |

## 6. AI 구현과 검증
- **학습 데이터**: 팀원이 직접 지문자 손 모양을 촬영해 관절 좌표로 저장 (1인당 25종 × 약 200프레임)
- **모델**: SVM으로 기준 성능을 확인한 뒤, 작은 신경망(MLP)을 학습해 TFLite로 변환하여 라즈베리파이에서 실행
- **검증**: 학습에 쓰지 않은 사람의 데이터로 정확도 측정, 혼동행렬로 헷갈리는 자모를 찾아 데이터 보강
- **단어 추천 AI**: 자모별 인식 확률과 민원 단어 사전을 함께 써서 오인식 단어를 바로잡음 (예: 듬본 → 등본). 자동으로 바꾸지 않고 사용자가 버튼으로 선택

## 7. 소프트웨어 구조
- **캡처 스레드**: 웹캠을 계속 읽고 최신 프레임 1장만 보관 → 인식이 느려도 영상이 밀리지 않음
- **인식 루프**: 전처리 → 관절 추출 → 분류 → 안정화 → 한글 조합
- **입출력**: `gpiozero`(LED·버튼·부저), `luma.oled` + 나눔고딕 폰트(OLED 한글 출력)
- **웹서버**: Flask-SocketIO(실시간 송수신) + SQLite(대화 기록)
- **코드 위치**: `src/pi/` — `main`, `camera`, `hand_tracker`, `classifier`, `stabilizer`, `hangul`, `hw/`, `web/`

## 8. 목표 성능과 검증 방법

| 항목 | 목표 | 검증 방법 |
|------|------|-----------|
| 처리 속도 | 라즈베리파이 4에서 15 FPS 이상 | 실행 중 FPS 로그 측정 |
| 자모 정확도 | 처음 보는 사람 기준 90% 이상 | 학습에 없던 팀원 데이터로 테스트 |
| 확정 시간 | 손 모양을 만든 뒤 1초 이내 | 확정까지 걸린 시간 기록 |
| 전달 지연 | 전송 후 직원 화면 표시까지 0.5초 이내 | 송신·수신 시각 비교 |
| 안정성 | 30분 연속 동작 중 오류 없음 | 연속 동작 시험 |

**속도 확보 방법**: 320×240 입력, MediaPipe 경량 모드(`model_complexity=0`), 캡처·인식 스레드 분리, TFLite 추론, 팬 케이스
